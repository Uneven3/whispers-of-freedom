# AGENTS.md

Reglas para cualquier agente/asistente que trabaje en este repo.

1. **Leé `docs/ARCHITECTURE.md` primero**, siempre, antes de tocar código —
   es la autoridad viva del proyecto (leyes §1-§19 + pipeline real).
2. **No asumas qué hace el código por su nombre.** Leé la lógica real antes
   de describir o depender de un comportamiento — un nombre puede mentir o
   quedar desactualizado.
3. **El usuario se puede equivocar.** No le des la razón por default en
   cosas donde está mal — corregilo con evidencia, igual que corregirías
   una asunción propia.
